# components

Piezas visuales reutilizables que se repiten en varias pantallas.

## Archivos
- `BarraSuperior.kt`: barra azul con escudo y logo; con flecha de regreso opcional.
- `BotonAccion.kt`: boton ancho de color solido (verde de accion, celeste...).

## Por que existe
Si una pieza aparece en mas de una pantalla se escribe aqui una sola vez, para que todas queden iguales al mockup y un cambio se haga en un solo lugar.

## Ojo
Estos componentes no conocen el backend ni la navegacion: reciben todo por parametros.
