# historial

Pantalla "Historial": lista de marcaciones del trabajador, de la mas reciente a la mas antigua.

- Usa: `ObtenerHistorialUseCase`.
- Backend: `GET /api/marcaciones/mi-historial`.
- Cada fila muestra el tipo (Entrada, Salida, etc.) y la fecha y hora. En el mockup las entradas y las salidas se distinguen por color.
